# 심사 시연 가이드

> 설치 없이 브라우저만으로 **실제 Pleos Connect 2.1 에뮬레이터** 위의 **실제 플리 APK**를 목소리로 써 볼 수 있습니다.
> 화면은 실시간 중계이며, 녹화나 모형이 아닙니다.

| | |
|---|---|
| 시연 포털 | https://fire-specialists-other-operators.trycloudflare.com/ |
| 준비물 | 데스크톱 Chrome(권장), 마이크(헤드셋 권장) |
| 소요 시간 | 음성 체험 3분 + Pleos 조작 2분 + 영상 1분 |

> 공개 터널 주소는 호스트가 다시 시작되면 바뀔 수 있습니다. 접속이 안 되면 제출 양식의 최신 주소를 확인해 주세요. 체험은 한 번에 한 명씩 3분이며, 나머지 접속자는 같은 화면을 관람합니다.

---

## 포털 구성

| 메뉴 | 주소 | 내용 |
|---|---|---|
| 앱 체험 | `/app` | 플리 앱 화면 + 내 목소리로 대화 |
| Pleos 시뮬레이터 | `/pleos` | 시스템 바·독·차량 3D까지 포함한 Pleos 전체 화면. 터치·홈·앱 전환·**차량 조건** 조작. 마이크 없이도 가능 |
| 자료 | `/resources` | 제품 소개 영상·영상 대본·기획서·체험용 APK |

## 1. 3분 음성 체험 — `/app`

1. **목소리로 시작하기**를 누르고 브라우저의 마이크 권한을 허용합니다. 3:00 타이머가 시작됩니다.
2. 플리의 “듣는 중” 안내가 나오면 아래 순서로 말해 보세요.

| 순서 | 이렇게 말해요 | 보이는 것 |
|---|---|---|
| ① | “내일 뭐 챙겨?” | 일정·날씨·목적지로 만든 **준비물 카드**, EDGE AGENT 칩에 확인 단계 |
| ② | “다 챙겼어!” | 카드 항목이 체크됨 |
| ③ | “앨범 만들어 줘” | 얼굴 인식으로 고른 **이야기 앨범**, 다른 아이 얼굴은 흐림 |
| ④ | “고래는 물고기야?” | 엣지 LLM의 짧은 아이 말투 답 |
| ⑤ | “끝말잇기 하자” | 두음법칙을 지키는 말놀이 |
| ⑥ | 플리가 말하는 도중 “플리야 쉿” → “다시 시작해” | 즉시 조용해지고, 명시적으로 다시 불러야 이어짐 |

3. 끝나면 **체험 마치기**를 누릅니다. 마이크 원음은 저장하지 않습니다.

> 공개 체험은 샘플 자료만 씁니다. 가족 개인 자료는 쓰지 않습니다.

---

## 2. 차가 먼저 말하는 순간 — `/pleos`

플리의 차별점은 **차량 신호가 트리거가 되어 먼저 제안**하는 것입니다.

1. **직접 조작하기**를 누르고 **차량 조건**에서 **D · 주행**(32km/h)을 고릅니다.
2. 플리가 출발 인사를 한 뒤, 잠시 후 **먼저** 말합니다.
   “집까지 13분 남았어요. 가는 길에 경기도서관이 있어요. 하연이가 요즘 그림 좋아하잖아요. 그림책 보러 잠깐 들를까요?”
3. `/app`에서 마이크를 켜 둔 상태라면 “거기 가 볼까?” 또는 “좋아!”라고 말해 보세요. **경유지 추가** 카드가 나옵니다. “괜찮아, 그냥 가자”라고 하면 경로를 그대로 둡니다. 공개 체험은 실제 경로를 바꾸지 않습니다.

| 차량 조건 | 확인해 볼 것 |
|---|---|
| **D · 주행 / 주행 · 70km/h** | 주행 중 플리는 화면 동작을 줄이고 음성 중심으로 바뀝니다. 왼쪽 Pleos 차량 화면이 끊기지 않습니다(플리가 말하는 동안 초당 28~30번) |
| **비 오는 날** | “밖에 비 와?” → 와이퍼 신호와 날씨로 답함 |
| **충전 켜기** | “충전 놀이터 열어 줘” → 충전 중 놀이 |
| **P · 정차** | 정차 중에는 숫자 놀이의 주판알 힌트를 화면으로 보여 줌 |
| **P · 정차 → 뒷문 열기** | 아이가 내리면 여정을 마치고 도착 기록(거리·스탬프)을 남김 |

## 3. 영상과 자료 — `/resources`

- **▷ 플리 소개 영상 보기** — 41초. 가족 장면은 AI 연출, **기능 장면은 이 포털과 같은 에뮬레이터에서 실제 APK를 녹화**했습니다. 재생 중 조작권과 마이크는 반환되고, **실시간으로 돌아가기**로 복귀합니다.
- **영상 대본 보기** — 모든 대사 자막.
- **기획서 PDF** — 12쪽. 문제·시나리오·아키텍처·에이전트 루프·MCP·경로 추천·음성·SDK·안전 설계.
- **APK** — Pleos Connect용 개발 서명 APK입니다. 일반 휴대전화용 앱이 아닙니다.

## 확인 포인트

| 항목 | 어디서 보이나 |
|---|---|
| 실제 Pleos SDK 연동 (Vehicle · NaviHelper · FusedLocation · STT · TTS) | `/pleos`에서 차량 조건을 바꾸면 플리의 말과 **우리 차** 패널이 바뀜 |
| 에이전틱 루프 | 답과 함께 나오는 **EDGE AGENT** 칩(계획 → 도구 → 관찰) |
| MCP 도구 | “내일 뭐 챙겨?”의 준비물이 일정 도구 결과에서 나옴. 모르면 지어내지 않음 |
| 먼저 제안 | 주행으로 바꾼 뒤 플리가 먼저 들를 곳을 말함 |
| 주행 안전 | “쉿”, 주행 중 동작 줄임, 경로 변경은 승인 뒤에만 |
| 개인정보 | 다른 아이 얼굴 흐림, 공개 체험은 샘플 자료, 원음 미저장 |

## 접속이 어려울 때

- **화면 연결 중**이 계속되면 **다시 연결**을 누릅니다.
- 다른 사람이 체험 중이면 관람 모드로 보입니다. 3분 뒤 차례가 돌아옵니다.
- 소리가 안 들리면 **소리 연결 다시 켜기**를 누릅니다.
- 포털이 열리지 않으면 저장소의 영상([가로](../media/pli-film-landscape.mp4) · [세로](../../demo-v2/preview.mp4))과 [기획서](../pli-pleos-product-brief.pdf)로 확인할 수 있습니다. 직접 실행은 [설치·실행 가이드](INSTALL.md)를 참고하세요.
